# Security policy

## Supported version

Security fixes are applied to the current `master` branch. Historical commits and forks listed for older openFrameworks releases are not maintained.

## Reporting a vulnerability

Do not open a public issue for a suspected vulnerability. Use GitHub's private **Report a vulnerability** option in the repository Security section and include:

- the affected version or commit
- a minimal proof of concept or malformed Alembic file
- expected and observed behavior
- potential impact

Please remove confidential scene data and personal information before submitting a report. The maintainers will acknowledge the report, investigate it, and coordinate disclosure after a fix is available.
